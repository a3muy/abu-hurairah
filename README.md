# موقع حلقات أبي هريرة

منصة إدارة حلقات التحفيظ: تسجيل الحفظ والمراجعة والتكرار، الحضور والغياب، المتعثرين، الإنجازات، رسائل الطلاب، والحجز الأسري.

الموقع ملفات جاهزة بدون أي برمجة أو تثبيت: تربطه بـ Firebase (للدخول والبيانات)، وترفعه على GitHub، وتنشره من Vercel أو GitHub Pages.

---

## الخطوة ١: إنشاء مشروع Firebase (مرة واحدة)

1. ادخل [console.firebase.google.com](https://console.firebase.google.com) واضغط **Add project**، وسمّه مثلًا `abu-hurairah`. (Google Analytics مو ضروري.)
2. **تسجيل الدخول:** من القائمة اختر **Build ← Authentication ← Get started**، ثم من **Sign-in method** فعّل **Email/Password** واحفظ.
3. **قاعدة البيانات:** اختر **Build ← Firestore Database ← Create database**، واختر الموقع `eur3` أو الأقرب لك، ثم **Start in production mode**.
4. **قواعد الأمان:** داخل Firestore افتح تبويب **Rules**، احذف الموجود والصق محتوى ملف `firestore.rules` كاملًا، واضغط **Publish**.
5. **ربط الموقع:** من ⚙️ **Project settings** انزل إلى **Your apps** واضغط أيقونة الويب `</>`، وسمّه مثلًا `web` (بدون Hosting)، واضغط **Register app**.
   راح يطلع لك كود فيه `firebaseConfig`. انسخ القيم الست والصقها في ملف **`js/firebase-config.js`** مكان كلمة `ضع_هنا`.

> ملاحظة: هذي القيم مو سرية، عادي تكون في GitHub. الحماية الحقيقية هي قواعد الأمان في الخطوة ٤.

## الخطوة ٢: رفع الملفات على GitHub

1. ادخل [github.com/new](https://github.com/new) وأنشئ مستودع جديد باسم مثلًا `abu-hurairah`.
2. اضغط **uploading an existing file**، واسحب **كل الملفات والمجلدات** اللي داخل هذا المجلد (`index.html` و`css` و`js` و`assets` وغيرها)، ثم **Commit changes**.
   مهم: يكون `index.html` في أول المستودع، مو داخل مجلد ثاني.

## الخطوة ٣: نشر الموقع (اختر طريقة وحدة)

**الطريقة أ: Vercel (مثل موقع الفلاح)**
1. ادخل [vercel.com/new](https://vercel.com/new) وسجّل بحساب GitHub.
2. اختر مستودع `abu-hurairah` واضغط **Import** ثم **Deploy** بدون تغيير أي إعداد.
3. يعطيك رابط مثل `abu-hurairah.vercel.app`.

**الطريقة ب: GitHub Pages**
1. في المستودع افتح **Settings ← Pages**.
2. في **Branch** اختر `main` والمجلد `/ (root)` واضغط **Save**.
3. بعد دقيقة يطلع الرابط مثل `اسمك.github.io/abu-hurairah`.

## الخطوة ٤: السماح للرابط بتسجيل الدخول

في Firebase افتح **Authentication ← Settings ← Authorized domains ← Add domain**، وأضف رابط موقعك بدون `https://`، مثل:
`abu-hurairah.vercel.app` أو `اسمك.github.io`

## الخطوة ٥: أول دخول

1. افتح الموقع، وتحت نموذج الدخول اضغط **«أنشئ حساب المشرف الرئيسي»**. هذا يظهر مرة وحدة فقط، فسوّه أنت أول ما تنشر الموقع.
2. من **الإعدادات** حدّد تاريخ بداية الفصل ونهايته، وأيام الحلقة (افتراضيًا الأحد إلى الأربعاء).
3. من **المشرفين** أضف بقية المشرفين (لكل واحد بريد وكلمة مرور).
4. من **الطلاب** أضف الطلاب. الطالب يدخل باسم المستخدم أو رقم الهوية مع كلمة المرور اللي تحددها له.

---

## تحديث الموقع لاحقًا

لما أرسل لك نسخة جديدة: افتح المستودع في GitHub ← **Add file ← Upload files** ← اسحب الملفات الجديدة فوق القديمة ← **Commit changes**.
Vercel وGitHub Pages يحدّثون الموقع تلقائيًا خلال دقيقة.
**انتبه:** لا تستبدل ملف `js/firebase-config.js` بنسخة فيها `ضع_هنا`، لأنه فيه إعدادات مشروعك.

## الصلاحيات

| | المشرف الرئيسي | المشرف | الطالب |
|---|---|---|---|
| الطلاب وتسجيل الحفظ والحضور | كل الطلاب | طلابه فقط | — |
| المشرفين والنسخ الاحتياطي وإعدادات الفصل | ✓ | — | — |
| المتعثرين والتقارير والرسائل والحجوزات | ✓ | ✓ | — |
| لوحتي، سجلاتي والتكرار، الحجز الأسري، الإنجازات، تواصل معنا | — | — | ✓ |

## ملاحظات

- **كلمة مرور طالب نسيها:** إذا كان له بريد حقيقي يوصله رابط التغيير من «إعادة تعيين كلمة المرور». وإذا ما له بريد، غيّرها من Firebase ← Authentication ← Users.
- **حذف طالب أو مشرف** يحذف بياناته من الموقع، وحساب الدخول نفسه يبقى في Authentication (ما يقدر يدخل)، وتقدر تحذفه من هناك.
- **النسخ الاحتياطي:** نزّل نسخة كل فترة من صفحة النسخ الاحتياطي.
- **التكلفة:** خطة Firebase المجانية (Spark) تكفي حلقة عادية.
